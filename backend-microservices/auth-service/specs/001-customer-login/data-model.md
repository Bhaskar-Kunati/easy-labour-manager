# Data Model: Customer Login (`auth-service`)

## Entities

### User Entity (`com.easylabour.authservice.domain.model.User`)
- **Table**: `users` (PostgreSQL `el_db`)
- **Fields**:
  - `id`: `String` (UUID generated via `@GeneratedValue(strategy = GenerationType.UUID)`)
  - `mobileNumber`: `String` (Unique, Not Null)
  - `email`: `String` (Unique, Nullable)
  - `passwordHash`: `String` (Not Null, hashed using Spring Security `PasswordEncoder`)
  - `role`: `UserRole` Enum (`CUSTOMER`, `WORKER`, `ADMIN`)
  - `status`: `UserStatus` Enum (`ACTIVE`, `INACTIVE`, `SUSPENDED`, `BLOCKED`)
  - `isVerified`: `boolean`
  - `createdAt`: `LocalDateTime`
  - `updatedAt`: `LocalDateTime`

### Login Request DTO (Payload Map / Request Body)
- `mobileNumber`: `String` (Required)
- `password`: `String` (Required)

### Login Response DTO
- `token`: `String` (JWT Access Token generated by `JwtService`)
- `user`: `User` (User entity details)
