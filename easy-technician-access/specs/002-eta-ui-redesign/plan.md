# Implementation Plan: ETA Web Application UI Redesign

**Branch**: `002-eta-ui-redesign` | **Date**: November 14, 2026 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `easy-technician-access/specs/002-eta-ui-redesign/spec.md`

## Summary

Redesign the EasyTechnicianAccess (ETA) Next.js web application UI to closely match the reference screenshot (`design-reference/eta-homepage-reference.png`). Implements the primary professional blue `#0866E9` color palette, dark navy headings, white backgrounds, light blue section backgrounds, rounded cards (`rounded-2xl`), subtle shadows, clean spacing, modern typography, homepage header with Bengaluru location selector, hero section with service search, service category grid with icons, why-choose-ETA section, how-it-works 3-step workflow, app promotion banner, trust statistics, and consistent propagation across customer and technician dashboards and pages while preserving Spring Boot microservices, API Gateway routing, JWT authentication, and existing backend contracts.

## Technical Context

**Language/Version**: TypeScript 5 / JavaScript (Node.js 18+)

**Primary Dependencies**: Next.js 14, React 18, Tailwind CSS, Lucide React, TanStack React Query, Axios, Zod, React Hook Form

**Storage**: LocalStorage / Cookie-based JWT auth tokens and user session state

**Testing**: Jest, React Testing Library

**Target Platform**: Modern web browsers (Desktop, Tablet, Mobile)

**Project Type**: Web Application Frontend (Next.js)

**Performance Goals**: Lighthouse performance score 90+, fast client-side navigation, optimized image loading

**Constraints**: Preserve all Spring Boot microservices, API Gateway contracts, JWT authentication, RBAC, and existing customer/technician workflows. No fake endpoints or mocked backend data.

**Scale/Scope**: Frontend UI redesign across public homepage, customer portal, and technician portal.

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

- **Code Quality & Type Safety**: TypeScript strict mode maintained; no untyped casts or suppressed warnings.
- **Backend Preservation**: Spring Boot microservices, API Gateway, JWT auth, and database schemas left untouched.
- **Testing**: Jest unit and component tests updated and validated.
